# Chapter / Unit / Lesson / Problem / Option

학습 콘텐츠의 구조와 제출 규칙을 다룬다. 제출로 받는 보상은 `learning.md`를 따른다.

- 학습 단위는 챕터 > 유닛 > 레슨 > 문제 순으로 중첩된다
- 챕터는 분류를 하나 가진다. 분류는 CS, COMMON(직군 공통 기반), SERVER, WEB, AOS, IOS, LANGUAGE다
- 직군 옵션은 CS를 뺀 6개이고 COMMON, SERVER, WEB, AOS, IOS, LANGUAGE 순서로 분류 값 그대로 내려준다
- 웹은 CS 챕터 목록과 직군별 챕터 목록을 나눠 조회한다. 두 목록은 챕터 id 순으로 보여주고, 진행률은 전체 챕터 목록과 같은 기준을 따른다
- 직군별 챕터 조회에 CS를 요청하면 거절한다
- 전체 챕터 목록(안드로이드)은 분류와 상관없이 모든 챕터를 보여준다
- 유닛은 챕터 안에서 1부터 시작하는 순서를 가진다. 같은 챕터 안에서 순서는 겹치지 않는다
- 챕터의 유닛 목록은 이 순서대로 보여준다
- 챕터와 유닛의 진행률은 "푼 레슨 수 / 전체 레슨 수"이고 소수점을 버린다
- 행성 정복률은 "푼 서로 다른 레슨 수 / 전체 레슨 수"이고 반올림한다
- 문제는 객관식과 주관식이 있다. 객관식은 선택지 id가, 주관식은 제출 내용이 반드시 있어야 한다
- 레슨 정답률은 0~100 범위만 저장할 수 있다
- 레슨 제출은 덮어쓰지 않고 이력으로 쌓인다. 재제출해도 이전 기록은 남는다
