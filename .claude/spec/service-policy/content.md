# Chapter / Unit / Lesson / Problem / Option

학습 콘텐츠의 구조와 제출 규칙을 다룬다. 제출로 받는 보상은 `learning.md`를 따른다.

- 학습 단위는 챕터 > 유닛 > 레슨 > 문제 순으로 중첩된다
- 챕터와 유닛의 진행률은 "푼 레슨 수 / 전체 레슨 수"이고 소수점을 버린다
- 행성 정복률은 "푼 서로 다른 레슨 수 / 전체 레슨 수"이고 반올림한다
- 문제는 객관식과 주관식이 있다. 객관식은 선택지 id가, 주관식은 제출 내용이 반드시 있어야 한다
- 레슨 정답률은 0~100 범위만 저장할 수 있다
- 레슨 제출은 덮어쓰지 않고 이력으로 쌓인다. 재제출해도 이전 기록은 남는다
