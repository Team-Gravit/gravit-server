# CS Note

- CS 노트는 서버가 보관한 마크다운 문서를 그대로 내려준다. 사용자가 쓰거나 고칠 수 없다
- 노트는 유닛 단위로 제공되고, 유닛에 지정된 노트 경로로 문서를 찾는다. 한 노트를 두 유닛이 가리킬 수 없다
- 유닛에 노트가 지정되지 않았거나, 지정된 노트 문서가 없으면 404로 응답한다
- 노트는 CS 기본 챕터 5개(자료구조, 알고리즘, 네트워크, 데이터베이스, 운영체제)와 직무 트랙 챕터 17개, 총 22개 챕터의 유닛에 제공된다
