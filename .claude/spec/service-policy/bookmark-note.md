# Bookmark / WrongAnsweredNote

- 북마크는 문제 단위이고 같은 문제를 중복 등록할 수 없다
- 북마크 해제는 등록된 북마크에만 할 수 있다
- 오답 노트는 문제를 틀리면 자동 등록된다. 사용자가 직접 추가하지 않는다
- 오답 노트는 삭제하지 않고 해결 상태로 바꾼다. 이력이 남는다
- 유닛 조회 시 그 유닛에 북마크와 오답이 하나라도 있는지를 접근 가능 여부로 함께 내려준다. 진입 차단은 클라이언트가 이 값으로 판단한다
