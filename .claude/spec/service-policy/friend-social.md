# Friend / Social

- 팔로우는 단방향이다. 승인 절차가 없고 팔로우하면 즉시 성립한다
- 자기 자신은 팔로우할 수 없고, 같은 상대를 중복으로 팔로우할 수 없다
- 언팔로우와 팔로워 거절은 둘 다 팔로우 관계를 지우는 동작이다
- 소셜 피드에 올라가는 활동은 세 가지다. 연속 학습 마일스톤 달성, 레벨업, 리그 티어 승급
- 연속 학습 마일스톤은 7, 30, 60, 100, 200, 300, 365일이고, 365일을 넘기면 100일 단위로 계속 쌓인다
- 리그는 승급만 피드에 올라간다. 강등은 올라가지 않는다
- 축하는 한 피드에 한 번만 보낼 수 있고, 같은 상대에게는 하루 3번까지만 보낼 수 있다
- 축하를 받은 사용자는 축하 1회당 리그 점수 5점을 받는다. 축하를 보낸 사용자는 받지 않는다
- 축하 여부는 피드 화면과 알림함에서 같은 값으로 보인다
- 축하한 피드는 피드 목록에서 사라지지 않고 축하 완료 상태로 남는다. 목록에서 빼려면 숨기기를 해야 한다
- 유저 추천에 보여주는 함께 팔로우 수는 내가 팔로우하는 사람 중 그 추천 대상을 팔로우하는 사람 수다
- 친구 검색 결과는 한 페이지에 10명이다
- 친구 검색은 대소문자를 구분하지 않는다. 핸들 검색은 앞에 붙은 @를 떼고 영문과 숫자만 비교하고, 닉네임 검색은 영문, 숫자, 한글만 비교한다. 비교할 문자가 하나도 남지 않으면 빈 결과를 준다
