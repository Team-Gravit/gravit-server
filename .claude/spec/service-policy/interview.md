# Interview

## 면접 모드

- 면접 모드는 공통 CS와 직무별 두 가지다
- 공통 CS 모드는 직무와 기술 스택을 고르지 않는다
- 직무별 모드는 직무(백엔드, 프론트엔드, 안드로이드, iOS)와 기술 스택을 고른다
- 직무별 모드의 기술 스택은 공통, 프레임워크, 언어 세 축으로 나뉘고 축마다 채점 집계 카테고리가 하나씩 붙는다
- 답변 입력 방식은 텍스트와 음성 중 하나를 세션 시작 시 고르며 세션 도중에 바꿀 수 없다

## 난이도와 레벨

- 질문 난이도(상, 중, 하)는 질문 하나의 속성이고, 세션 레벨(상, 중, 하)은 세션 전체의 속성이다. 두 값은 별개 축이다
- 세션 레벨이 어떤 난이도의 질문을 몇 개씩 뽑는지 - 미정

## 세션 상태

- 세션은 진행 중으로 시작해 채점 중을 거쳐 완료로 끝난다
- 세션을 끝내면 즉시 완료가 되지 않고 채점 중으로 바뀐다. 채점은 응답을 돌려준 뒤에 이루어진다
- 채점 중인 세션을 조회하면 진행 정보와 채점 중 표시만 나가고 점수는 나가지 않는다
- 완료된 세션을 조회할 때만 점수가 나간다
- 진행 중인 세션이 실패로 끝나면 중단 상태가 되고, 중단된 세션은 점수 없이 진행 정보만 나간다

## 문항과 배점

- 한 세션은 5문항으로 구성된다
- 문항당 20점이고 세션 총점은 100점이다

| 축 | 판정 기준 | 문항당 배점 |
|------|------|--------|
| 정확도 | 핵심 개념 커버리지 + 보조 개념 가산 + 잘못된 개념 감점 | 14 |
| 조리 - 구조성 | 결론을 먼저 말했는가 | 3 |
| 조리 - 명료성 | 군더더기가 있으면 차감 | 3 |

- 세션의 만점은 세션을 시작한 시점의 문항 수로 정해진다. 이후 배점 정책이 바뀌어도 이미 시작한 세션의 만점은 그대로다
- 정확도 점수에는 오답 배율(1.0, 0.5, 0.2)이 적용된다

## 질문과 핵심 개념

- 질문과 핵심 개념은 미리 저장해둔다. 채점 때 만들지 않는다
- 핵심 개념은 개념명과 필수/보조 구분만 저장한다. 인정 기준, 누락 안내 문구, 모범답안은 저장하지 않는다
- 인정 기준과 누락 안내 문구는 채점 시점에 AI가 판단하고 생성한다
- **개념명은 판정 가능한 문장으로 작성한다.** 채점 프롬프트가 개념명만 받아 판정하므로 개념명의 서술 수준이 채점 품질을 결정한다
  - 나쁜 예: `시간복잡도`
  - 좋은 예: `평균 시간복잡도가 O(n log n)임을 언급`
- 질문마다 학습 유닛이 하나 연결된다. 약점으로 진단된 질문에서 해당 유닛으로 학습을 이어간다

## 채점

- 채점 판정은 AI가 하고 점수 계산은 고정 규칙으로 한다
- 답변마다 개념별로 전달과 누락을 판정한다. 전달한 개념은 답변에서 근거 구간을 남기고, 누락한 개념은 안내 문구를 남긴다
- 답변에서 잘못 말한 구간이 있으면 교정 문장과 함께 남긴다
- 답변이 비어 있으면 AI를 거치지 않고 0점 처리한다. 음성 입력의 변환 결과가 비어 있는 경우도 같다
- 무응답 답변은 전체 개념을 누락으로 기록하고, 잘못된 개념은 남기지 않는다
- 문항별 채점이 모두 끝나면 세션 종합 점수를 계산하고 완료로 바꾼다
