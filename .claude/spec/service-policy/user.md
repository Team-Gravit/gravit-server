# User

- 레벨은 1에서 10까지이고, 누적 XP로 결정된다. 구간 시작 XP는 0, 100, 200, 400, 700, 1100, 1600, 2200, 2900, 3700이다
- 10레벨은 상한이 없다. 최고 레벨의 진행률은 항상 100%로 표시한다
- XP를 얻는 경로는 레슨 첫 제출, 미션 완료, 면접 완료 세 가지다. 지급량은 `learning.md`, `mission.md`, `interview.md`를 따른다
- 온보딩은 한 번만 할 수 있다. 이미 온보딩한 사용자가 다시 시도하면 실패한다
- 닉네임은 2~8자이고 한글, 영문, 숫자만 쓸 수 있다. 공백과 특수문자는 허용하지 않는다
- 프로필 이미지 번호는 1~20 사이만 쓸 수 있다
- 자동 발급 핸들은 영문 소문자와 숫자로 된 8자리다
- 탈퇴는 메일 인증을 거친다. 탈퇴 링크의 인증 코드는 180초 뒤 만료되고 한 번 쓰면 소멸한다
- 탈퇴하면 즉시 지우지 않고 비활성 처리하며, 핸들을 반납해 다른 사용자가 쓸 수 있게 한다. 실제 데이터 삭제는 탈퇴 7일 뒤다
- 실제 삭제 때 그 사용자의 학습 진행, 레슨과 문제 제출 기록, 일일 학습 기록, 북마크, 오답 노트, 리그 참여와 시즌 이력, 미션, 신고, 문의와 답변, 팔로우 관계(팔로우와 팔로워 모두), 올린 소셜 피드와 받은 피드, 주고받은 축하, 알림, 푸시 토큰, 작성한 공지를 함께 지운다
- 실제 삭제 때 면접 기록(세션, 고른 주제, 답안, 채점 결과)과 면접 음성 녹음 원본도 함께 지운다. 음성 원본은 제출하지 않은 녹음과 취소한 세션의 녹음까지 지운다
- 음성 원본을 지우지 못해도 기록은 예정대로 지우고, 음성 원본은 따로 다시 시도한다
- 탈퇴 상태 계정으로 로그인하면 로그인을 막고 탈퇴 상태임을 알린다. 사용자가 복구를 선택하면 그때 되살린다. 복구는 실제 삭제 전(탈퇴 7일 이내)에만 가능하고, 복구 시 핸들은 새로 발급된다. 복구한 계정은 실제 삭제 대상에서 빠진다
- 탈퇴한 사용자는 다른 사용자의 조회 결과에 나타나지 않는다
- 마지막 접속 시각은 하루에 한 번만 갱신한다
- 하루의 첫 접속은 그날의 활성 이력으로 남는다. 인증된 요청이면 종류와 관계없이 활성으로 본다. 이력은 기능 배포 시점부터 쌓이며 과거는 소급되지 않는다
- 활성 이력은 탈퇴 7일 뒤 실제 삭제 때도 지우지 않는다. 사용자 번호와 날짜만 남고 식별 정보는 없으며, 관리자 대시보드의 과거 집계 수치가 탈퇴로 소급해 바뀌지 않게 하기 위함이다
