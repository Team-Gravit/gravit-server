# Notice

- 공지는 어드민만 작성한다. 사용자는 읽기만 한다
- 공지를 게시 상태로 새로 등록해야 전체 활성 사용자의 알림함에 알림이 쌓인다. 임시 저장 상태로 만들면 알림이 나가지 않는다
- 알림이 나가는 시점은 등록 한 번뿐이다. 임시 저장으로 만든 공지를 나중에 게시로 바꿔도 알림은 나가지 않고, 이미 게시된 공지의 제목이나 내용을 고쳐도 다시 나가지 않는다
- 의도한 규칙은 공지 하나당 사용자별 알림 한 건이지만, 발송 재시도 경로에 중복 방지 키가 없어 재시도가 걸리면 같은 공지 알림이 여러 건 쌓일 수 있다
