# Admin / Report

- 어드민 기능은 어드민 권한 계정만 쓸 수 있다. 권한 부여 방식은 `auth-security.md`를 따른다
- 문제 신고는 존재하는 문제에만 할 수 있다
- 학습 콘텐츠는 스테이징에서 만들고 검수한 뒤 운영으로 승격한다. 승격 전에는 사용자에게 보이지 않는다
- 승격 검수 기준은 레슨당 문제 6개(객관식 4개, 주관식 2개)이고, 객관식 문제는 선택지가 4개여야 한다. 기준에 맞지 않으면 승격되지 않는다
- 이미 승격된 라벨은 다시 승격할 수 없다
- 새 콘텐츠 알림은 종류만 정의되어 있고 레슨 승격과 아직 연결되어 있지 않다. 현재는 QA 경로에서 본인에게 보내는 것만 동작한다
