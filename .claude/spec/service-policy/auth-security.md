# Auth / Security

- 로그인은 소셜 로그인(Google, Kakao, Naver, Apple)만 지원한다. 자체 계정 가입은 없다. Apple 로그인은 웹에서만 지원한다
- 소셜 로그인은 제공자가 발급한 토큰을 서버가 제공자에게 확인한 뒤에만 성립한다. 클라이언트가 보낸 사용자 정보를 그대로 신뢰하지 않는다
- 안드로이드 로그인은 Google, Kakao는 id_token을, Naver는 액세스 토큰을 서버에 전달한다
- Apple 웹 로그인은 클라이언트가 받은 인가 코드를 서버가 Apple에 직접 교환하고, Apple이 서명한 id_token의 발급자와 대상이 Gravit인지 확인한 뒤에만 성립한다. 이메일이 없으면 로그인을 거부한다
- 소셜 계정 식별자는 `{제공자}_{제공자측 식별자}` 형태로 만들고, 이 값이 같으면 같은 사용자로 본다
- 처음 로그인하는 계정은 그 자리에서 회원가입되고, 닉네임은 소셜 계정 이름, 프로필 이미지는 1번으로 시작한다
- Apple은 검증 가능한 이름을 주지 않으므로 Apple 계정의 첫 닉네임은 `애플사용자`로 시작한다. 닉네임은 온보딩에서 정한다
- Apple 로그인 때 Apple이 발급한 연결 토큰을 암호화해 보관하고, 로그인할 때마다 최신 값으로 바꾼다. 이 토큰은 탈퇴 시 Apple 연결을 해제하는 데만 쓴다(`user.md`)
- 탈퇴 상태 계정의 로그인 처리는 `user.md`를 따른다
- 어드민 화이트리스트에 이메일이 등록되어 있으면 가입 시점에 어드민으로 만들고, 이미 가입한 사용자는 로그인 시점에 어드민으로 승격한다. 승격만 있고 자동 강등은 없다
- 액세스 토큰은 2시간, 리프레시 토큰은 14일 뒤 만료된다
