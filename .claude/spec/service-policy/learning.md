# Learning / Answer / DailyLearningRecord

- **레슨을 처음 제출할 때만 보상을 지급한다. 재제출은 기록만 쌓이고 XP, 리그 점수, 미션 진행도, 일일 학습 기록이 모두 늘지 않는다**
- 레슨 1회 기본 보상은 20점이고, 실제 지급량은 `20 × 정답률 ÷ 100`을 반올림한 값이다. XP와 리그 점수 모두 같은 방식으로 계산한다
- 즉 정답률이 낮으면 보상도 줄고, 정답률 0%면 보상이 0이다
- 연속 학습일은 하루에 한 번만 오른다. 같은 날 몇 번을 풀어도 1일로 센다
- 연속 학습일은 보상과 판정 기준이 다르다. 그날의 첫 학습이면 재제출이어도 연속 학습일은 오른다
- 연속 학습일은 매일 자정 직후에 정산한다. 그날 학습하지 않았으면 0으로 초기화하고, 학습했으면 다음 날 판정을 위해 표시만 지운다
- 틀린 문제는 오답 노트에 자동으로 올라간다. 같은 문제를 또 틀리면 다시 오답 상태가 된다
- 레슨 제출 API는 생성된 제출 아이디만 응답한다. 결과 화면에 필요한 리그명, 레벨, 유닛 요약은 그 아이디로 별도 조회한다
- 결과 조회는 본인의 제출만 가능하다. 없는 제출이거나 타인의 제출이면 같은 예외로 응답한다
- 결과 화면의 리그명과 레벨은 이번 제출로 확정된 값이 아니라 조회 시점의 현재 값이다. 보상이 재시도 큐로 넘어간 경우 아직 반영 전 값이 보일 수 있고, 재조회하면 수렴한다
- 주간 리포트는 월요일 시작 기준이고, 이번 주와 직전 3주의 레슨 수 차이를 함께 보여준다
- 학습 기록 조회 가능 연도는 가입 연도부터 올해까지다
- 학습 순위 백분위는 값이 없으면 100%로 본다
