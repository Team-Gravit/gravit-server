# 마이그레이션 & SQL

## Flyway 마이그레이션

- 위치: `src/main/resources/db/migration/`, 파일명: `V{N}__{description}.sql` (언더스코어 2개, description은 snake_case)
- 파일 최상단에 파일명을 주석으로 남겨라: `-- V6__add_accuracy_to_lesson_submission.sql`
- 적용된 파일은 절대 수정·삭제하지 마라 (Flyway checksum 실패). 변경은 항상 새 버전 파일로 추가하라
- 각 SQL 문 앞에 목적을 주석으로 설명하라

## SQL 스타일

- 테이블·컬럼명은 snake_case (`wrong_answered_note`, `profile_img_number`)
- PK: `id BIGINT GENERATED BY DEFAULT AS IDENTITY`
- FK 컬럼: `{참조테이블}_id` (`problem_id`, `user_id`)
- timestamp: `TIMESTAMP(6)`
- enum: `VARCHAR(255)` + `CHECK` 제약
- JSON: `JSONB`
- 인덱스: `CREATE INDEX IF NOT EXISTS ix_{테이블}_{용도}`
